CLI & AI MCP Configuration

Integrate Pluck directly into Claude Desktop, Cursor, and your command line.

1. Pluck CLI Quickstart

Authenticate your terminal in one command:

npx pluck-cli login
2. Claude Desktop & Cursor (Stdio MCP)

Add this block to your claude_desktop_config.json:

{
  "mcpServers": {
    "pluck": {
      "command": "npx",
      "args": ["-y", "pluck-cli", "mcp"],
      "env": {
        "PLUCK_TOKEN": "pluck_pat_YOUR_TOKEN_HERE"
      }
    }
  }
}
